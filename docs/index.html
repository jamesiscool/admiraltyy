Admiraltyy

Unified Usenet media automation. Movies, TV, and downloads in one modern platform.

🎬

Unified Library

Movies and TV series in one interface — no more switching between Sonarr and Radarr.

⚡

Bun-Powered

Lightning-fast TypeScript backend with instant startup and minimal resource usage.

🎯

Quality Rules

Transparent, configurable rules for quality, size, language, and format preferences.

📡

NZBGet Integration

Reliable downloads via NZBGet's proven JSON-RPC engine.

🗂️

Auto Organization

Automatic folder structure for movies and series/season hierarchies.

🔍

Smart Discovery

TMDB and TheTVDB integration for rich metadata and recommendations.

Quick Start

# Clone and install
git clone https://github.com/jlles/admiraltyy.git
cd admiraltyy
bun install

# Run
bun run dev
