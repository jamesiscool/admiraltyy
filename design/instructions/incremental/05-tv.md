# Milestone 5: TV

The TV section lets users browse their tracked TV series library, view episodes organized by season, and manage monitoring at series, season, or episode level.

## Overview

Similar to Movies but with hierarchical data: Series → Seasons → Episodes. Episodes without a file are considered "wanted" if monitored.

## Episode Status Definitions

- **Downloaded**: Episode has a file on disk
- **Missing**: Episode's air date has passed but no file (urgent - needs action)
- **Airing**: Episode has a future air date and is being monitored

## Monitoring Behavior

### Series-level
When series is unmonitored:
- All season/episode toggles become disabled
- Toggles maintain their state (don't reset)
- When series is re-monitored, previous states apply

### Season-level
- Monitoring a season → monitors all episodes in that season
- Unmonitoring a season → unmonitors all episodes in that season

### Episode-level
- Individual episodes can be toggled
- Only enabled when parent series AND season are monitored

## Season Ordering

Most recent season appears first in the UI.

```typescript
const orderedSeasons = [...series.seasons].sort(
  (a, b) => b.seasonNumber - a.seasonNumber
);
```

## API Endpoints

```typescript
// List series
GET /api/series
  ?search=term
  &status=missing|complete|continuing
  &quality=1080p
  &monitored=true

// Get series with seasons/episodes
GET /api/series/:id

// Add series
POST /api/series
  { tvdbId: number, qualityPreference: string }

// Update series
PATCH /api/series/:id
  { monitored?: boolean, qualityPreference?: string }

// Update season
PATCH /api/series/:id/seasons/:seasonId
  { monitored: boolean }

// Update episode
PATCH /api/series/:id/episodes/:episodeId
  { monitored: boolean }

// Delete series
DELETE /api/series/:id

// Search TVDB
GET /api/search/series?q=term
```
